## Summary

This sample writeup shows the content shape for the blog. Keep the first section short: target, bug class, impact, and the result.

## Recondawdawd

- Map the application surface.
- Identify trust boundaries.
- Capture request and response pairs that prove the behavior.

## Exploit Path

```http
POST /api/profile HTTP/1.1
Host: lab.local
Content-Type: application/json

{"displayName":"<script>alert(document.domain)</script>"}
```

The important part is the reasoning chain. Include only the payloads, logs, and screenshots that move the proof forward.

## Impact

Explain what an attacker can do with the bug. Tie the impact to data access, account actions, privilege changes, or business logic abuse.

## Fix

Validate input at the boundary, encode output at render time, and add regression tests for the vulnerable sink.
